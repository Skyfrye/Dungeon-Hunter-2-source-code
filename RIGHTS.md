# Provenance and rights

Dungeon Hunter 2 and its data are the property of Gameloft. This repository is an independent reconstruction; it is not
Gameloft source code and the game is not relicensed as open source.

- `build_data/` holds the original game data and resources, used with Gameloft's permission.
- `recovered/` holds material derived from the original binary (symbols, pseudocode, assembly, scripts); it keeps the rights
  status of the original.
- The reconstructed code and the tools were written for this project.
- Third-party libraries (Lua, Box2D, gameswf, TinyXML, zlib, libpng, libjpeg, FreeType, Irrlicht, …) keep their own licences
  in their `upstream/` folders.
